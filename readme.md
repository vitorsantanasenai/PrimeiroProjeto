# Git e GitHub - Controle de Versão

Este repositório foi criado para praticar os principais conceitos de **Git e GitHub**, incluindo criação de repositórios, commits, branches, Pull Requests, merge e commits em coautoria.

---

## Objetivo

O objetivo deste projeto é aprender na prática como funciona o controle de versão utilizando Git e GitHub.

Durante a atividade serão praticados os seguintes conceitos:

- Git
- GitHub
- Repositório
- Clone
- Commit
- Push
- Pull
- Branch
- Merge
- Pull Request
- Code Review
- Coautoria
- Resolução de conflitos

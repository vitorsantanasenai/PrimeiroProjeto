# O que é Git?

Git é um sistema de controle de versão utilizado para acompanhar as alterações realizadas nos arquivos de um projeto.

Com ele podemos registrar diferentes versões do código durante o desenvolvimento.

Exemplo:

```text
Projeto
   |
   v
Alteração no código
   |
   v
git add
   |
   v
git commit
   |
   v
Nova versão registrada
```

---

# O que é GitHub?

GitHub é uma plataforma utilizada para armazenar e compartilhar projetos que utilizam Git.

Podemos pensar da seguinte maneira:

```text
Git
Controle de versão
executado no computador

        ↓

GitHub
Repositório remoto
armazenado na Internet
```

---

# Git x GitHub

| Git | GitHub |
|---|---|
| Controle de versão | Plataforma de hospedagem |
| Funciona localmente | Funciona online |
| Registra alterações | Armazena os repositórios |
| Utiliza commits | Permite Pull Requests |
| Possui branches | Permite colaboração |
